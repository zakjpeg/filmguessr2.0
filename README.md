# FilmGuessr

Like GeoGuessr, but for film geeks.

In FilmGuessr, you have two minutes to analyze one frame of a movie guess it's title.

Version 2.0 introduces **authentication, persistent game sessions, experience levels, public profiles, leaderboards, and more**.

## Features

* User authentication
* Profile customization

## In Progress

* Gameplay
* Match history
* Profile analytics

## To do

Built with **Next.js, TypeScript, Tailwind CSS, Supabase, and Vercel**.
